# Статические сайты

Четыре самостоятельных одностраничных шаблона с готовыми английскими текстами. У каждого один `index.html`; CSS и иллюстрации находятся внутри него. Сборка, JavaScript и внешние ресурсы не нужны.

| Каталог | Название | Содержание и оформление |
|---|---|---|
| `field-notes` | Field Notes | Небольшой дневник наблюдений за природой. Светлая бумага, зелёные акценты, ботаническая иллюстрация. |
| `ceramic-studio` | Earth & Form | Заметки о форме и повседневных предметах. Тёплая терракота, керамические объекты, крупная типографика. |
| `trail-journal` | Outside, Slowly | Размышления о прогулках. Тёмная палитра, многослойный пейзаж, короткие записи. |
| `reading-room` | Margins | Заметки о чтении. Газетная композиция, книжная иллюстрация, спокойная светлая палитра. |

## Использование

Содержимое выбранного каталога можно скопировать в webroot обычного статического HTTP-сервера. Для предварительного просмотра откройте `index.html` в браузере. Все ссылки ведут к разделам той же страницы, сетевые запросы к другим сайтам не выполняются.

Страницы содержат адаптивную вёрстку, метаданные, навигацию с клавиатуры и ссылку для перехода к основному содержимому. Иллюстрации декоративные и не мешают озвучиванию страницы. Анимаций, форм, аналитики, cookies и скрытых действий нет.

Тексты, HTML, CSS и SVG созданы для этого проекта; сторонние шаблоны, фотографии, шрифты и цитаты не использованы. Их можно изменять и размещать вместе с проектом. Сайты не заявляют о существовании реальных компаний, услугах, наградах, адресах или контактных лицах.

## Редактирование

Название страницы, описание, заголовки и абзацы редактируются непосредственно в HTML. Цвета большинства шаблонов заданы переменными в начале `<style>`. Не нужно добавлять домен в код: страницы используют только внутренние ссылки, поэтому переносятся на другой hostname без изменений.
